# Timeline navigation

Issue: [#31](https://github.com/IanSzymanski/squidware/issues/31).

Open **Timeline options** in the transport for the timeline controls. **Zoom in** and **Zoom out** keep the visible playhead anchored; **Fit whole show** restores the full count axis. At maximum zoom a count occupies 24 CSS pixels. While the timeline is zoomed, a pan slider under it changes only the visible window; its arrow keys provide a keyboard alternative. Panning switches **Follow playhead** off, and enabling follow brings the current count back into view. Follow also handles stepping, playback and loop rewinds. **Find set** in the transport lists each set's number, name, counts and tempo, including all 128 sets in a production, and searches them by number or name. Choosing a set pauses playback and brings its arrival into view.

The opening picture is set 01 at show count zero. The timeline is one count-proportional lane: a ruler, a track of set segments, problem markers and, when a recording is attached, an audio track. Each segment describes an incoming move and selects its destination set. The ruler shows measures at a regular stride, or counts when **Ruler in counts** is selected, and omits labels that would collide. Segments show their set number at a regular stride where they are wide enough; hover/focus help gives the set's name and arrival. Short moves remain proportionally narrow at Fit; zoom or **Find set** makes their arrivals intentional targets. Tab visits the opening set, then each later set in order.

The transport shows the current or destination set (in **Find set**), the local move count, the measure and the absolute show count; the measure and show readouts hide in narrow windows. At a boundary the move readout is labeled **At set** and shows the completed incoming move, such as 8 / 8. A fraction after that boundary is labeled **Move**, and **Find set** shows an arrow before the next destination's number. Readouts use `sampleTimeline`. While paused they display up to three decimal places. While playing, the show count, local move count, score beat, playhead value text and read-only field banner name the last whole count reached, so they change once per count; the underlying clock and playhead stay fractional. A single-set show has only the opening picture and disables count stepping/playback.

Each transport tier has its own glyph family: First/Last set use double chevrons, Previous/Next set use skip glyphs and Previous/Next count read −1 and +1 (the comma and period keys). The buttons beside Play and the existing comma/period commands pause and move exactly one count backward/forward from the current value, retaining fractions and clamping at zero/show end. For example, period moves 8.25 to 9.25. Shortcuts retain their existing preference bindings and do not run while typing in inputs, textareas, selects or editable content. Clicking or dragging the ruler scrubs fractionally within the visible window through the shared seek command.

Zoom, pan, follow and control expansion are session view state. They do not enter `.squid`, affect tempo/geometry, create undo transactions or mark the production dirty. Loading a different production resets the count viewport to Fit/follow. The audio lane remains hidden without an attachment and clips its existing overview to the visible count window. Measure/rehearsal content remains #51 and show-wide problem markers remain #45; the count-axis component leaves a lane insertion point for those features without inventing musical metadata.

## Review evidence

Design guidance sections 1–5 apply. This uses existing neutral theme tokens, Lucide icons, `HelpButton`/`Tooltip`, native range/select controls and the shared set/seek/count commands. Controls collapse by default to preserve field space. Expanded controls temporarily use an additional row; enlarged narrow windows use the existing scrollable workspace, and focusing controls scrolls them into view. Narrow field columns use a compact transport with an audio icon and omit First/Last set buttons; the all-set picker and previous/next set commands retain those navigation paths.

Before/after captures are in [evidence/timeline](evidence/timeline). The baseline is main `7b055bb`; after captures use the same deterministic 128-set production with alternating 1-, 8-, 32- and 1,024-count moves. Dark, light, high-contrast and 1024×720 at 125% are inspected. Measurements and interaction results are recorded in `review.json`. Default 1366×768 layout retains the approximately 120 px transport/timeline and 470 px field targets; the expanded view is temporary and trades field height for navigation controls.

`pnpm test:timeline` (also in the default desktop certification matrix) exercises every set with native select typeahead, pointer ruler scrubbing, zoom, keyboard pan/follow, comma/period and transport steps, fractional/boundary readouts, text-input exclusion, playback and enlarged-theme access. Source tests cover engine boundary agreement, exact fractional steps, 128-set short/long moves and nonoverlapping labels. Navigation leaves the serialized production unchanged, so save/reopen and undo data formats are unchanged.

Local visual interaction evidence uses production Electron under Xvfb with `--no-sandbox`, because this cloud host has neither a configured setuid helper nor usable unprivileged namespaces. This is targeted UI evidence, not sandbox/platform certification. Source/native/contract checks run separately. Hosted CI must run the normal sandboxed desktop suite on Windows, macOS and Linux. The earlier macOS audio screenshot restoration failure was resolved by the shared viewport fixes and fixed-layout capture sequencing in #145–#147; [source and three-platform certification on merged main b4a7bcd](https://github.com/IanSzymanski/squidware/actions/runs/39978590555) passed. Future release sources still require their own exact-source certification. No human writer or school-hardware qualification is claimed.

CI follow-up: the narrow transport follows the main workspace width, keeping field space when Cast or enlarged panels narrow the center column. In the current shell, loop, metronome and speed (and, on the narrowest layouts, rehearsal passages and audio) move into **More playback options**, and the narrowest transport hides First/Last set; **Find set** and the previous/next set buttons keep those navigation paths. The shared screenshot helper nudges/restores native client dimensions rather than outer frame bounds, with a regression simulating changing native frame insets. This addresses the earlier macOS two-pixel restoration drift without relaxing viewport assertions.
