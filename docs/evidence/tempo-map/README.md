The three-picture fixture uses 16 counts: 120→240 BPM over counts 0–8, then 240→120 over 8–16, with 0.9 s at count 4 and 0.6 s at 8. Independent analytic duration is `8 × ln(2) + 1.5 = 7.045177...` seconds. The tests compare diagnostic beat times to that formula for silent 1.5× and recorded 1× playback. Reported sub-microsecond scheduling differences are numerical comparisons of audio-thread times, not physical latency measurements. The production processor reports rendered-sample times as well; the final runner bounds their error by 3 ms and validates beats against the active posted media-synchronization plan when virtual media/device clocks reanchor under parallel load. Silent/source schedules require every beat. A recorded onset can be omitted only when a recorded stop/reanchor demonstrably canceled its old future onset after the new media time had passed it; unexplained omissions, duplicates and reversed beats still fail. The existing metronome owner retains waveform/output-thread coverage.

During a [recorded fermata](tempo-fermata.png), the recording advances across a forced 400 ms renderer stall while the field remains exactly at count 4. The metronome is silent between the held count's attack and its next beat. The compact accessible hold readout adds no height: field height with the existing audio lane remains 454 px, the same as the paused attached-audio view. Its 31 px difference from the silent 485 px field is the existing optional recording lane; the new map adds no lane. The Inspector labels BPM as a base value when a map overrides it.

Native v3 save/reopen, partial hold pause/resume, scrubbing/count stepping, instantaneous-tempo count-in and recorded range loops across both fermatas pass. Source tests independently cover all five speeds, analytic/quadrature comparisons, monotonic round trips and plateaus, exact legacy timing, splits, immutable commands, bounds and 256 ranges plus 256 holds. Native boundaries retain the map through file save, recovery and audio packages. CSV timing and native PDF export are exercised; the print owner independently inspects the actual timing appendix.
