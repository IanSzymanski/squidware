# Live formation review

Reviewed on a Linux x64 software host, Node 24.19.0, Electron 44.7.0, Xvfb and software rendering. This is automated interaction and agent rendered-output review; no physical-device or human usability result is claimed. Windows/macOS packaging and full platform coverage remain CI's responsibility.

The native workflow and existing formation-assignment/startup suites passed together at implementation content hash `f13129e6d1209b9ee73bf72dbcc55cb9361aa17c37ed67400efc49a507d25512`, before these evidence-only copies were added. `related-workflows.json` preserves the source identity, runtime and individual results. All 741 source tests passed; 85 native/service/harness tests and 30 format/release contracts passed. A parallel build/desktop run initially caused three unrelated source timeouts; they passed in isolation and the complete source suite then passed without competing work. Two initial native iterations exposed focus-help obstruction in the test and Enter interception on a native disclosure control; the final runner dismisses prior focus help and production keyboard handling preserves Enter/Space for summary elements.

Design guidance §§1–4 applies. The implementation reuses the Inspector, NumberField, HelpButton/Tooltip, formation handles, assignment planner, command registry and contextual Apply/Cancel. Default-scale field height remains 485 px at 1366×768 in all three themes, above the 470 px target. At 1120×768 and 125% scale it is 296.25 CSS px: the shared header/field tools wrap at this enlarged scale. The Inspector scrolls; name, membership/redistribution and persistent Apply/Cancel remain reachable, with numeric controls below. This narrower enlarged state is outside the default-scale laptop target and retains the established compact layout. No new outer workspace row is introduced.

The native test covers checkbox/name creation; keyboard reopening; endpoint drag and Escape; arc bulge/block dimensions and columns; membership checkbox redistribution; Enter/Space disclosure behavior; one-action undo/redo; manual-dot detachment and explicit redistribution; cross-set copying without editing the source; conflict messages and blocked Apply; detach/undo; and native v7 save/reopen. Source tests cover all five kinds, added/removed/empty memberships, vacant slot reload, assignment identity, drag cancellation, roster removal, duplicate IDs, pending/stale/boundary rejection, hold constraints and equality of committed dots, serialization, playback and analysis.

`results.json` retains 2/64/500-member preview readiness measurements (two animation frames included): approximately 2007/556/116 ms on this host. These are single local observations after theme/layout changes, include cold scheduling/rendering and are not algorithm benchmarks or hardware budgets. All requested members rendered and accepted; the scalar evaluator remains shared by live preview, acceptance and file validation. Stored picture positions remain the common playback/analysis/export input. Format fixtures and independent JSON Schema/native codec tests cover bounds, ownership/slot errors, v1–v6 compatibility and downgrade protection.
