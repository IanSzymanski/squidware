# Independent movement schedules — software review

Issue [#74](https://github.com/IanSzymanski/squidware/issues/74). This evidence covers one performer's independent hold/straight/cubic intervals within a shared show move, with up to 32 ordered intervals, intermediate destinations and derived final-picture endpoints.

## Results

- Source certification: **686 source tests and 28 format/release checks passed**. Coverage includes mixed two-performer schedules, every boundary, explicit/implicit holds, fractional counts, local easing, zero-distance intervals and loops, hold-only endpoint compatibility, overlap/order/count/coordinate rejection, stable IDs, caller-owned draft isolation, undo/redo, older-wire refusal, musical fermatas and maximum production round-trip.
- An exact-boundary regression covers count `0.21` in a three-count move: converting count to progress and back loses precision. Scheduled sampling now receives the original local count directly while preserving the legacy full-move line arithmetic. Existing migration fixtures still compare exactly.
- **83 native tests passed**, including native v6 open/save and rejection of overlapping intervals without changing the saved file.
- [Final workflow report](final-workflows.json): **movement-schedule, editor, commands, print, smoke and analysis passed**. [Related report](related-workflows.json): **paths, split-transition and analysis-rules passed** on the preceding source. That report preserves the initial schedule harness failure: focus help consumed Escape after a routing-only check, leaving its modal open. The corrected harness blurs focus help and explicitly waits for modal dismissal before continuing.
- [The final targeted replay](latest-targeted.json) explicitly records both SVG transforms during live playback: A remains at `(20,25)` while B advances, with the count moving from 6.532 to 7.251.
- The schedule suite uses native pointer selection, dropdown typeahead, numeric typing and Enter/Escape. It covers invalid overlaps and cancellation without history; independent A/B schedules with one undo action each; analytic field scrubs; real playback through A's hold while B/show count advance; v6 save/reopen; safe routing away from the simple curve editor; native CSV/PDF export; supported themes; and enlarged keyboard Apply. Collected renderer errors/unhandled promises are empty.
- [Independent export inspection](export-inspection.json) passed all six CSV rows and three PDF pages, checking interval descriptions, the 17-second first arrival including the musical fermata, unavailable peak fields and every extracted word box within page bounds. [The PDF](scheduled.pdf) was also rasterized and visually inspected. [Existing print inspection](print-inspection.txt) passed all layout/paper fixtures.

This follows existing enlarged workspace behavior and is not a default-size field regression.

## Performance and limits

[Microbenchmark](performance.json): 128-set shows with 32 mixed line/cubic/hold intervals per performer in the first move. For 2, 64 and 500 performers, mean sampling is **0.004, 0.024 and 0.252 ms**; p95 **0.007, 0.033 and 0.365 ms**. Full codec validation averages **1.28, 4.79 and 30.06 ms**. The largest encoded fixture is **5,531,137 UTF-8 bytes**, below the existing 10 MiB limit. Each timing uses 2,000 samples after 200 warmups on this host. These are engine/codec measurements, not rendered-frame budgets or physical-device claims. An all-moves/all-performers maximum schedule can exceed the file budget; no unlimited-file claim is made.

Detailed spacing/stride analysis remains explicitly unavailable pending #76. Worker inputs retain the interval geometry, but neither worker nor reference API emits chord-based clearance results. Count resizing, splitting and predecessor-changing set operations reject scheduled paths atomically pending #77. Field handles remain #75; the separate viewer is not implemented. Schedules use parameter timing within travels, not constant arc-length speed. Endpoint-picture edits retain intermediate/control coordinates; hold-only schedules require matching endpoint positions.

Host: Linux x64, Node 24.19.0, pnpm 11.25.0, Electron 44.7.0, Xvfb/software rendering. Native chooser destinations are controlled; renderer, native input, preload, filesystem and playback are real. Electron and subprocess-dependent tests run outside the command filesystem sandbox with Chromium sandboxing retained. D-Bus and PDF font-metadata diagnostics are nonfatal. No human-signoff, physical-device or hosted Windows/macOS pass is claimed. Reports retain tested source hashes preceding evidence copies and later documentation-only records; hosted CI certifies the pushed source separately.
