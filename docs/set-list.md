# The set strip, Find set and direct reorder

The left Set list panel is gone. In Write mode every set is a card in the set strip under the timeline, in show order. A card shows the formation thumbnail, the absolute set number, the incoming move counts, the name and, when the move into the set has problems, their count. The opening card has no counts because it has no incoming move. Card help gives the full name, counts and tempo; the Inspector always shows the tempo. The current card is outlined and scrolls into view when the set changes. Turn **Set thumbnails** off in **Timeline options** for a compact row of numbers and names; the choice is saved on this device, independently of the project. **Hide set strip** in the transport removes the strip, and it is also hidden in short windows and in Plan and Rehearse modes.

One card is in the Tab sequence. Left/Right go to the previous or next set, and Home/End to the first or last. The strip scrolls sideways with the mouse wheel.

**Find set** in the transport shows the current set's number and name. Select it to search every set. It accepts an exact one-based set number (`40`, `040`, or `set 40`), or a literal, case-insensitive part of a name. Results keep the original set numbers and order and show each set's counts and tempo. Enter goes to the highlighted match, which starts as the first. Up/Down move through the matches. Escape closes the search and returns focus to **Find set**. Search and navigation create no history; going to a set pauses playback and arrives at the set.

To move the current set directly, open the Command palette and choose **Move current set to position N**; set 40 can move to position 12 in one operation. An exact number always selects that position (typing 1 never runs position 10), and invalid and unchanged positions cannot apply. Every reorder path confirms the new position, and a move into or out of the opening says how show timing changed; the palette entries for those moves say so beforehand. **Set actions → Move earlier** and **Move later** in the Inspector move one position at a time. A card can also be dragged onto another card: dropping an earlier set on a later card places it after that card, while dropping a later set on an earlier card places it before. The insertion mark identifies the resulting position; the strip scrolls near its edges during a drag. Alt+Left/Right moves a focused card one absolute show position.

## What follows a reordered set

- Pictures keep their stable IDs, names, notes and performer coordinates. The active picture remains selected by ID, even when another picture moves across its old index. Playback stops at the active picture's new arrival count and clears rehearsal focus.
- Each surviving incoming move follows its destination picture, preserving its ID, counts, tempo, transition and supported line-path segments. Its source is rewired to the new previous picture. A changed source clears that move's declared marching directions because they described different travel; declarations on unchanged connections remain intact.
- The new first picture has zero elapsed counts and no incoming move. If it previously had an incoming move, that move is removed and its tempo/transition become inert opening metadata. The former opening picture receives a fresh 32-count move using its former stored opening tempo/transition and implicit straight paths. This preserves the established v1/v2 editing policy; changing the opening can change show duration. The confirmation after an opening reorder says so, and the reorder controls' help explains it beforehand.
- Musical anchors remain at absolute show counts. Reordering that would strand an anchor beyond the new duration fails without changing data, history, selection or playback. Rehearsal references continue to use stable picture/move IDs; a reference to a removed incoming move becomes repairable through the existing passage editor.

Each accepted reorder is one named undo action. Undo restores the exact previous pictures, moves, paths and declarations; redo reuses the accepted move IDs. Undo/redo preserve the currently selected picture whenever it survives, falling back to a remaining index if it has been removed. Reordering is unavailable during pending edits, previews or dialogs. Drag requests carry the reviewed revision and project session; stale or external drops cannot reorder a different project.

V1 files migrate through the canonical v2 codec before editing; no format field is added for compact rows or search. Native save, recovery, coordinate export and timeline/playback consume the same reordered canonical project. The set strip ends with **Add set**; when the strip is hidden, **Add set** is in the transport.
