# Editable Production sheet

Open **Sheet** to enter the production without visiting every set's Inspector. Set numbers identify rows; edit Name, Counts, BPM, Notes, Meter and Mark. Read-only measure/beat positions appear beside the set numbers. Selecting a cell arrives at that set, synchronizing the timeline and Inspector. **Field** opens the active row in Design. The compact summary shows total counts and written-tempo runtime.

Enter or blur commits a valid cell as one named undo action. Tab/Shift+Tab traverse columns and wrap rows; Enter and Up/Down traverse rows, with Shift+Enter moving upward in single-line fields. Alt+Left/Right moves columns without consuming text-caret arrows. Shift+Enter adds a line to Notes. Escape cancels the current input. Tab at the ends leaves the sheet. The sheet has one normal Tab entry; direct clicks can focus any cell. The opening count is read-only 0. An unrelated pending Inspector input blocks changing the sheet’s active set until it is corrected or canceled. Invalid sheet input stays pending until corrected or canceled, and cannot be saved as if it were committed data. An error identifies its row/column and offers Return to input and Cancel input.

**Add row** appends a hold at the end, retaining all performers at the preceding positions. Name, timing and notes remain editable. It uses the current personal new-set count preference, the preceding BPM, constant speed and blank notes. Adding a row is one undo action; it never duplicates an incoming travel path. Use the established set creation actions for different geometry. Set reordering remains separate from the sheet.

## Spreadsheet paste

Focus the starting cell and paste a TSV or multiline CSV range, or use **Paste range** for any CSV/TSV text, including one-line CSV. The dialog states the starting set and column and lets you correct the source text before applying. Supply a rectangular range without headings or the read-only set-number column. Full rows use **Name, Counts, BPM, Notes, Meter, Mark**; a partial range begins at the focused column. Quote commas, tabs, newlines or double quotes within cells using standard spreadsheet quoting (`"A, B"`, `"a ""quote"""`). UTF-8 BOM and CRLF/LF records are accepted.

Every supplied cell appears beside its previous value. Blank Notes clear notes; omitted columns keep their existing values. Empty names or numeric cells are errors. Rows beyond the existing sheet append holds as described above; supplied cells replace their defaults. The opening must have 0 counts, later sets 1–1024 integer counts, BPM 20–400 (decimals allowed), names at most 160 characters, notes at most 10,000 characters and at most 128 sets. Blank Meter cells inherit the score map (clearing an explicit change at that set); the opening meter is required. Meter text uses `4/4`, `6/8:3+3` or `7/8:2+2+3`. Mark cells set or clear a unique rehearsal label at the set’s absolute arrival count. Limits come from `PROJECT_LIMITS`, with the same validation as other commands and saved projects. Oversized/malformed text and nonrectangular ranges fail visibly, with no truncation, clamping or partial commit.

**Apply paste** validates the complete range again through `sheet.apply`. Every row and added hold is one named undo action; Undo/Redo restores timing, notes, names and added rows together. Cancel/Escape leaves the project and history unchanged. A project revision/session change invalidates the preview and requires a fresh paste. Pending previews count as unsaved drafts and block saving or project replacement. Existing performer coordinates, IDs, transition/easing settings and unsupplied fields are preserved; changed move counts resize explicit line timing through the shared set-update operation. The playhead returns to the active set and stops playback after a sheet edit.

The optional v2 score metadata now stores meter changes, pickups and rehearsal labels. Use **Score map** to edit events between set arrivals, set pickup counts, choose the first full measure number or navigate by measure/beat. Musical anchors remain at absolute show counts when drill counts change; invalid maps block the edit with an explanation. See [musical semantics](score-map.md).

## Validation and design

[Shared design guidance](DESIGN_GUIDANCE.md) sections 1–5 apply. The sheet replaces oversized summary cards with a compact toolbar, reuses shared theme colors, typography, HelpButton, Modal, commands, history and project validation, and keeps the surrounding Save/Undo/Export/workspace/transport controls. Current rows use both text and a visual highlight; errors include row/column text and explicit error labels. The scrolling table retains its header and reveals focused inputs below it. The normal Design layout is unchanged.

The `production-sheet` owner exercises real production Electron keyboard/pointer paths, native clipboard, native save/reopen, malformed and over-limit data, stale review, 128-set/500-performer editing, all 512 cells in one paste, cancel/undo, supported themes and narrow/enlarged layouts. Source tests cover parser edge cases, independent cell errors, command atomicity, shared geometry/path preservation and format round trips. [Review evidence](evidence/production-sheet/README.md) records rendered screenshots and measured layouts. Hosted Windows/macOS/Linux certification and package verification remain separate from local Linux checks.
