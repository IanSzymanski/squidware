# Editable Bézier formations

Select at least two performers while paused at a set in 2D. Open Formation tools and choose **Bézier curve** or **Bézier wave** (also available in Commands). Existing Arc and Wave tools retain their behavior. Both Bézier presets enter the same point editor and keep editable geometry on the active set.

Drag square anchors or round tangent handles on the field. Selecting a handle selects its anchor in the Inspector. The Curve anchor and Point or tangent selectors plus X/Y fields provide keyboard entry. Pointer snapping uses the production's existing grid/marking rules; numeric entry specifies exact yards. Translating an anchor carries its handles. Edits that would put any control outside the field are rejected with an explanation, preserving the last valid preview.

Corner joins have independent handles. Smooth joins align opposite tangents while retaining the other handle's length; symmetric joins mirror the changed handle. Zero-length handles are allowed. Modes apply at interior joins; the first incoming and last outgoing handles do not define a segment. **Split after** inserts a midpoint by exact de Casteljau subdivision, retaining existing anchor IDs and changing adjacent symmetric joins to smooth when required. Up to 33 anchors are supported. **Delete anchor** reconnects the remaining neighboring controls and changes the preview's shape; at least two anchors must remain. Inspect that preview before Apply.

Members occupy equal distances along the curve using the same adaptive cubic/arc-length math as travel routes, with a .001 yd total length budget and .0005 yd local parameter bound. Endpoints and frozen member ordering are deterministic. Positional/Roster reassignment is explicit. Vacant slots remain after an individual dot is moved/detached; Redistribute members explicitly closes those gaps. Unrelated performers and travel definitions retain their values. Self-crossing shapes are permitted and equal along-curve intervals do not imply physical clearance; existing transition analysis remains applicable.

**Apply formation** accepts the complete preview as one named undo step. **Cancel/Escape** discards it; Escape during a pointer gesture first restores that gesture's starting geometry. Reopen through the saved live formation's Edit button. Copy-to-set previews the same geometry, modes and slots on the target set, using existing ownership/conflict behavior. Save/reopen persists anchors and modes in format v9, along with geometry-derived positions, membership and slots. Earlier applications reject this version instead of silently discarding curve controls.

Validation and rendered evidence: [Bézier formation review](evidence/bezier-formations/README.md). This feature shapes destinations; drawn travel routes and count-based group motion retain their separate editors.
