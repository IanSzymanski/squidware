# Constrained assignment comparison

Select 2–500 performers while paused at a set in 2D. Start a formation preview, or Edit a saved formation, then choose **Optimize assignment…** in Formation tools. The command palette exposes the same action. The selected performers and occupied destination slots are explicit; vacant slots stay vacant. Geometry, performer IDs and Cast order stay fixed during comparison.

Choose a member and destination to pin that pairing or prohibit it. Pins reserve the destination for that member. Section rules default to each destination’s current section; clear individual rules or all section rules explicitly to permit exchanges. Enter an instrument/role tag and required slot role when needed. Tags belong to this formation, match exactly after outer whitespace is trimmed, and are never inferred from names or section labels. Blank means unknown. Unknown members cannot fill role-restricted slots unless **Allow unknown roles** is selected; an explicitly different tag still cannot fill the slot.

**Keep this section’s current order** captures the selected section members’ current sequence and explicit slot sequence. Its start control chooses another contiguous band of occupied slots. This rule fixes those member-to-slot pairs; it is deliberately stronger than a relative-order-only constraint. Remove the rule to allow other arrangements. Overlapping/conflicting pins, groups, restrictions and prohibitions make a request infeasible; no rule is weakened automatically. Scatter pins remain fixed by identity and must be changed in the scatter editor.

**Compare proposals** evaluates the current mapping and two deterministic alternatives:

- **Shortest total travel** minimizes summed path lengths over available incoming and outgoing moves. With no adjacent move, it minimizes placement distance from the selected set’s saved dots.
- **Balanced member travel** minimizes the sum of squared member travel, where each member’s distance includes both adjacent moves. It discourages uneven travel but does not minimize the longest route or guarantee fewer crossings, lower step demand or lower total travel.

Both alternatives obey all hard rules. The solver finds a complete minimum-cost assignment on the evaluated length matrix; prohibited/incompatible edges are unavailable rather than large penalties. Curves use the shared adaptive length estimator (.001 yd total chord/control-polygon gap per path when converged). Unchanged move paths, intermediate endpoints, timing, holds, easing, direction declarations and analysis thresholds remain authoritative. Fixed final endpoints/holds may prohibit a reassignment. The optimizer changes no path definition or timing.

Cards compare total selected travel, longest member travel, selected peak demand bounds in yd/count, and all-cast spacing/crossing and stride flags on the available adjacent moves. Counts aggregate findings from both moves; they are not unique geometric intersections or clearance guarantees. Possible detailed findings remain labeled possible. Peak demand uses the same bounded derivative evaluator as detailed analysis, including holds and independently timed submoves; unconverged bounds remain explicit. The incoming/outgoing count preview uses playback’s evaluator. Squares mark unchanged slots. **Show paths** controls presentation only.

**Use proposal** returns the reviewed mapping and constraints to the formation preview. **Apply formation** commits one named undo transaction. Compare, Cancel/Escape, worker failure and infeasible requests leave the production/history unchanged. A changed production, set, selection or preview blocks acceptance and requires reopening the review. Worker cancellation terminates the calculation; a 20-second work budget and 30-second watchdog return explicit failures without accepting partial work. Smaller selections or simpler paths can be retried.

Saved constraints keep the formation editable. Reopening and copying to another set retain the exact mapping/rules; contradictory Cast/section changes fail validation. Review or explicitly clear constraints before changing membership, switching assignment mode or redistributing slots. Geometry edits retain member slots. Explicit detachment (including ordinary per-dot editing) removes that member’s pins, prohibitions and tags, prunes order groups and preserves remaining slot numbers; vacant section/role rules remain available for later review. Constraints persist in [format v11](../format/FORMAT.md), which older applications reject rather than discard. Other projects keep their least required format version.

The deterministic two-member reference fixture has lengths `[[0,6],[6,10]]`: shortest keeps routes 0/10 yd (total 10), while balanced chooses 6/6 yd (total 12). In eight linear counts their peak demands are 1.25 and .75 yd/count respectively. The four-member crossing fixture reduces 320 yd across two eased moves to zero while retaining an unrelated pair.
